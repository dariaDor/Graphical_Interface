# Лабораторная работа №1
## Аникина Дарья 6233

Класс Window наследуется от QWidget и описывает логику и интерфейс главного окна.

* Конструктор класса:
  * Устанавливает начальный размер окна 400x400 пикселей
  * Создает текстовую метку `QLabel` по центру окна с текстом `"Текст"`.
  * Создает кнопку `QPushButton` с надписью `"Кнопка"`.
  * Связывает событие клика по кнопке (`clicked.connect`) с методом `change_to_image`.

* **`change_to_image(self)`**: Обработчик нажатия кнопки.
  * Загружает изображение из файла.
  * Масштабирует его до размеров 400x400 пикселей.
  * Заменяет текст в `QLabel` на загруженное изображение.
  * Подгоняет размер виджета метки под контент с помощью `adjustSize()`.
